# Rick and Morty

Aplicação em Vue 3 para consumir a API pública do Rick and Morty e listar personagens com paginação.

## Funcionalidades

- Listagem de personagens da API do Rick and Morty
- Cards com nome, foto e local de residência
- Indicador visual de status: vivo, morto ou desconhecido
- Paginação dos resultados retornados pela API

## Como executar

```bash
npm install
npm run dev
```

## Build de produção

```bash
npm run build
```
